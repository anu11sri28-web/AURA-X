SYSTEM ARCHITECTURE & METHODOLOGY

About WeatherGuard AI.

Transparent architectural documentation, machine learning models, and data provenance.

MISSION & PURPOSE

Detecting the Anomalous. Tracking the Extremes.

WeatherGuard AI provides automated screening and real-time tracking of extreme weather phenomena including tropical cyclones, flash-flood deluges, gale-force winds, intense barometric depressions, and heatwaves.

By coupling real-time Open-Meteo observations with Scikit-learn unsupervised machine learning and Haversine spherical tracking, WeatherGuard AI flags atmospheric departures before standard warnings take effect.

AI/ML ARCHITECTURE

Isolation Forest + Explainable AI (XAI)

When sufficient historical data (at least 24 hours, typically 168 hours) is available, missing data is imputed with historical medians and normalized using StandardScaler. An Isolation Forest (120 estimators, 5% contamination) isolates multidimensional outliers.

Explainable AI feature contributions are calculated using Z-scores and relative percentiles so operators immediately understand which physical variables (temperature, wind, pressure, rainfall) triggered the alert.

DATA SOURCES & APIS

Open-Meteo Public Meteorological APIs

The system leverages Open-Meteo's open-access APIs: Forecast API, Historical Weather Archive API, and Geocoding API. Map tiles are provided by OpenStreetMap contributors. Charts are powered by Chart.js.

All data is fetched transparently with no secret keys required. If an API request fails, the application informs the user cleanly without substituting fabricated data.

TRACKING & GEOMETRY

Haversine Movement Vector Mathematics

Geographic movement direction and forward speed are calculated between successive timestamped coordinates using great-circle spherical trigonometry (Haversine formula). Stationary readings are identified explicitly.

Observations, forecast projections, and AI-estimated movements are strictly distinguished to avoid presenting unverified predictions as real observations.
